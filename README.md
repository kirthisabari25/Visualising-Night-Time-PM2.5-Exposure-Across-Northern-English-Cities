## **Visualising Night-Time PM2.5 Exposure Across Northern English Cities**
## **Overview**

This project examines night-time PM2.5 air pollution across selected Northern English cities using theory-driven data visualisation. By isolating night-time observations, the analysis reveals spatial and temporal inequalities that are often obscured by daily or annual averages.

Developed for the IJC445 Data Visualisation module, the project emphasises accessibility, ethical interpretation, and visualisation theory.

## **Research Question**

How does night-time PM2.5 exposure vary across Northern English cities, and what persistent inequalities emerge when night-time data are analysed separately?


## **Visualisations**

The composite visualisation includes:

Heat map – spatial–temporal inequality

Line chart – long-term night-time trends

Area chart – cumulative night-time exposure

Bar chart – cross-city comparison of typical exposure

## **Methods**

Visualisations created in R (ggplot2)

Guided by the ASSERT framework and Grammar of Graphics

Focus on accessibility and ethical communication
